# 大白饭余额 · DSH 插件

在 [DSH](https://github.com/deepseek-ai/deepseek-harness) 里直接看到[大白饭中转站](https://baifanapi.awstme.top/)还剩多少钱，不用打开网页。

- **输入框下方统计行**多一个余额条目，和「轮次 / 速度 / token / 缓存命中」排在一起
- **侧栏头像上方**一个余额按钮，收起成图标列时只剩硬币
- 每分钟自动刷新，点一下立刻重查，低于设定线变红
- 也能在对话里问「我余额还剩多少」，或输入框敲 `/balance`

支持两种口径，可以同时显示：

| 位置 | 口径 | 需要 | 说明 |
| --- | --- | --- | --- |
| 头像上方 | **账户余额** | 访问令牌 | 整个账户还剩多少钱 |
| 页面下方 | **key 额度** | api key | 这一条 key 自己被设的限额 |

数值前面会标明是「账户」还是「key额度」，回退时也跟着变，不会混淆。

## 安装

需要 **DSH Desktop 或 DSH Web**（Host-only 环境只有对话里的工具，没有界面）。

**方式一：压缩包（推荐）**

1. 下载 release 里的 `dsh-baifan-balance-x.y.z.zip` 并解压
2. DSH → **插件** → **Add plugin** → 选中解压出来的目录
3. 刷新页面（Ctrl+R）

**方式二：直接用包名（npm）**

DSH → **插件** → **Add plugin** → 填 `dsh-baifan-balance`。

插件管理器会通过 pnpm 从 registry 安装，并把精确版本写进 profile 依赖；之后在插件页可以直接升级/卸载。

**方式三：从 git 或源码**

Add plugin 同样接受 git 地址，也可以先 clone 再选目录：

```bash
git clone https://github.com/wanderlusty/dsh-baifan-balance.git
```

## 首次配置

点头像 → **设置** → **大白饭余额**：

| 字段 | 在哪拿 | 作用 |
| --- | --- | --- |
| **访问令牌**（推荐） | 站点 → 安全与访问 → 访问令牌 → 创建访问令牌 | 查账户完整余额，头像上方显示它 |
| api key | 站点 → API 密钥 | 查该 key 的限额，页面下方显示它 |
| 自动检测当前使用 key 的限额 | — | 默认开：自动认领 DSH 正在用的那条 api key，不用手填 |

> 访问令牌和 api key 尽量用**同一账号**的。key 的名字要靠账号级接口反查，跨账号只能显示末四位。

保存后立刻生效，不需要刷新页面。填凭据的输入框旁边有行内「保存」，不会漏点。

## 设置项

| 项 | 说明 |
| --- | --- |
| 显示位置 | 两处都显示 / 只在头像上方 / 只在页面下方 / 都不显示 |
| 刷新间隔 | 15–600 秒（点一下仍会立刻重查） |
| 信息密度 | 简洁 / 标准 / 详细（控制悬停明细和是否合并显示已用） |
| 强调色 | 跟随主题 / 品牌色 / 绿色 / 琥珀色（只染硬币图标） |
| 显示硬币图标 | 开 / 关 |
| 账户余额提醒 | 账户余额低于该值变红，填 0 关闭（默认 1） |
| key 额度提醒 | key 额度低于该值变红，填 0 关闭（默认 1） |
| 自动检测当前使用 key 的限额 | 关掉后页面下方只用手动填的 api key |

用量看板默认**折叠**，标题行直接显示**今日 / 昨日**花了多少，后面跟着所选天数的总量与请求数；展开后可选 7 / 14 / 30 天。统计按自然日（今天 0 点起算），需要访问令牌。

## 关于「无限制」

站点开着「令牌级别统计」时，`/v1/dashboard/billing/*` 回答的是**这一个 key** 的额度。key 没设上限时，站点会给一个哨兵值 `100000000`——本插件把它识别成**「无限制」**，而不是报一个假数字。

要按账户看余额，请配**访问令牌**。

## 其他入口

| 入口 | 用法 |
| --- | --- |
| `/balance` | 输入框敲，不走模型、不耗 token、结果只给你看；自动选口径 |
| `/balance account` | 强制账户口径 |
| `/balance key` | 强制 key 口径 |
| `/balance today` | 今日消耗与请求数（按自然日，需要访问令牌） |
| `/balance week` | 近 7 天消耗，附每日一行（同上） |

`today` / `week` 用**访问令牌**（站点用量接口是账号级的，`sk-` 查不到历史）。

> 早期版本还提供过一个 `relay_balance` 工具（让模型在对话里代查余额）。1.20.0 起移除：界面上的两个数字已经常驻可见，模型再代查一次只是多花 token。

## 凭据从哪来

优先级：插件配置 → 设置页保存的记录 → 环境变量 → 自动检测。

自动检测不再按固定顺序猜，而是**跟随 DSH 当前（默认）提供商的 `apiKeyEnv`**：读 `llm` 的提供商列表 + `settings` 投影拿到 `apiKeyEnv`，再用它去凭据服务取真实 key。读不到提供商信息时，才退回按常见引用名依次尝试。

- 账户口径：`BAIFAN_ACCESS_TOKEN` / `NEWAPI_ACCESS_TOKEN`
- key 口径：`DABAIFAN_API_KEY` / `BAIFAN_API_KEY` 等（仅作兜底）
- 早期版本还有「本包目录下 `secret.json`」这一层，1.20.0 已移除——它只服务开发机，分发时忘删就是泄密

## 隐私与安全

- **只读**：只发 GET，不改站点状态、不消耗额度
- 只连你自己设置的站点地址
- 密钥存进 DSH 的凭据存储，不写进插件配置文件
- 本地接口只接受本机回环访问，外部网页读不到你的余额
- 调用时若指定 `base_url`，必须同时给 `key`，避免配置里的凭据被送到别的站点

## 常见问题

**两处都不显示？** 设置里「显示位置」是不是「都不显示」。

**显示「未配置」？** 还没填凭据，见「首次配置」。

**显示「余额不可用」？** 悬停看具体原因（令牌失效 / 连不上 / 地址填错）。

**只想要对话入口？** 显示位置选「都不显示」，工具和 `/balance` 照常可用。

**key 只显示末四位？** 名字要靠账号级令牌表反查，跨账号查不到；换成同账号的访问令牌即可。

## 开发

纯 ESM，无构建步骤，不依赖任何 `@deepseek-ai/*` 包（直接构造注册表接受的 JSON Schema 定义）。

```
lib/index.js   Host 侧：工具、/balance 命令、两条本地路由、凭据与换算
client.js      浏览器侧：统计行条目、头像按钮、设置页
cordis.patch.yml  插入 profile 的插件行
locale/        Plugin Manager 里显示的标题与描述
```

```bash
npm pack              # 产出 tarball
npm publish --access public
```

覆盖率说明：核心换算与映射有自测脚本（未开源），UI 行为以真站点实测为准。
